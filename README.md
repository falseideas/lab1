# Сбор информации об операционной системе

## Описание работы

Лабораторная работа посвящена сбору информации о системе с помощью Python.

Скрипт определяет операционную систему, в которой он запущен, собирает сведения об ОС, компьютере и окружении Python, а затем сохраняет результат в файл `os_info.json`.

Поддерживаются Windows, Linux и macOS. Используются только модули стандартной библиотеки Python, поэтому установка дополнительных зависимостей не требуется.

## Собираемые параметры

| Раздел | Параметр | Описание |
|--------|----------|----------|
| `operating_system` | `name` | Название ОС: Windows, Linux или macOS |
| `operating_system` | `system` | Системное обозначение ОС: Windows, Linux или Darwin |
| `operating_system` | `release` | Выпуск ОС или ядра |
| `operating_system` | `version` | Сведения о версии и сборке ОС или ядра |
| `operating_system` | `architecture` | Архитектура компьютера |
| `operating_system` | `processor` | Сведения о процессоре, доступные через ОС |
| `python` | `version` | Версия Python |
| `python` | `implementation` | Реализация Python, например CPython |
| `python` | `executable` | Путь к исполняемому файлу интерпретатора |
| `computer` | `hostname` | Имя компьютера |
| `computer` | `cpu_count` | Количество логических процессоров |
| `environment` | `current_directory` | Текущая рабочая директория |
| `environment` | `home_directory` | Домашняя директория пользователя |
| `collection` | `timestamp_utc` | Дата и время сбора данных в UTC в формате ISO 8601 |

Набор параметров позволяет описать систему и среду выполнения без сбора избыточных данных. В зависимости от ОС поле `processor` может быть пустым. Если количество логических процессоров определить невозможно, `cpu_count` записывается как `null`.

## Запуск

Требуется Python 3. Сохраните скрипт в файл `topkod.py` и выполните в терминале:

```bash
python topkod.py
```

Если в системе Python 3 вызывается командой `python3`:

```bash
python3 topkod.py
```

## Результат работы

После запуска в текущей рабочей директории создаётся файл `os_info.json`. Если файл уже существует, его содержимое перезаписывается.

Данные сохраняются в кодировке UTF-8 с отступами для удобного чтения. JSON содержит пять разделов:

- `operating_system` — сведения об ОС и архитектуре;
- `python` — сведения об интерпретаторе Python;
- `computer` — имя компьютера и количество логических процессоров;
- `environment` — пути к рабочей и домашней директориям;
- `collection` — время сбора данных.

В консоль выводятся название ОС и полный путь к сохранённому файлу.
